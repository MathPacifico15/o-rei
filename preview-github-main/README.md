# Laboratório da versão main

Este laboratório usa uma cópia separada da branch `main`, no diretório irmão `../github-main-minigames`, para não misturar suas fontes com a versão atual. Com essa cópia e as dependências do projeto instaladas, execute `npx vite --config vite.github-main-minigames.config.ts`. O laboratório da branch atual usa `npx vite --config vite.minigames.config.ts`.

Os arquivos gerados em `preview-games/dist` não são necessários para executar os laboratórios.
